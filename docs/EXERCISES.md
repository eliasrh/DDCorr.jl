# Student investigation: find data, make SAC, assess correlations

Use the course and `DATA_DISCOVERY.md` as references. Submit a short notebook/report with exact commands, chosen parameters, source URLs, receipts and three annotated PNG figures. Do not submit thousands of waveform files. Instructor solutions are distributed separately after the exercise.

1. **Define a selection.** Choose an active interval and area in a regional catalogue. Aim for roughly 100 events and 12 stations; document fewer if that is all that exists. Find the catalogue's original download page or FDSN event endpoint. Record why this catalogue is suitable for small events. Explain whether its event IDs are supplied or generated by your importer.
2. **Find the recording network.** Use station-service documentation to identify the service base URL, network code, epoch, location and channel codes. Examine metadata before requesting waveforms. Show one complete channel ID and explain its four parts. Select stations by a declared rule unrelated to observed correlations.
3. **Find phase information.** Determine whether observed P/S picks are included. If not, locate a phase source or explicitly choose the teaching prediction route. State what your pick provenance establishes, and what it does not. Explain how a misplaced window centre affects a finite lag search.
4. **Prepare tables and SAC.** Use `prepare_tables.py --help` and the relevant subcommand help. Choose output directories, request limits and snippet lengths. Run the converter. Identify `manifest.json`, count requested versus successful combinations, and diagnose one missing selection if present. Repeat an identical request and check whether new bytes were downloaded.
5. **Inspect one file.** Use `bin/sac_info.jl` to display and plot a SAC. Identify its sample interval, origin, station, P and S fields. Explain reference time versus trace start versus origin. Check coverage before P and after S. Attach the output and PNG.
6. **Run DDCorr.** Inspect first, then correlate. Use the ID map to request two particular event pairs on one station for P and S. Locate the selection ledger. If a pair is not plotted, explain the relevant quality/coverage evidence; do not merely lower thresholds until it appears.
7. **Assess evidence.** Annotate one strong and one marginal/noisy example. Identify the fixed waveform, positive-lag convention and competing peaks. Show one station/phase matrix PNG and explain grey cells and the diagonal. Change one justified setting, predict what it should affect, rerun, and compare evidence. Do not infer real timing uncertainty from printed decimal places.
8. **Prepare a handoff.** Identify the matching catalogue, station list, dt.cc and ID map for one run. Explain which events are isolated, how weights are defined, and what further checks are needed before interpreting relocation.

A successful exercise is a reproducible, reasoned assessment, including failures and missing data. It is not a competition to maximize accepted correlations.

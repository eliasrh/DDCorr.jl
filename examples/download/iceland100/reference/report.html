IDs are sequential across valid input events, including isolated events. Original ID map. Near-identical arrival flags are review evidence; no events were automatically deleted.

What does the lag mean? Each waveform is first centred on its own phase pick. A positive lag of +0.10 s means the matching feature in event j is 0.10 s later within that pick-centred window; shift j left by 0.10 s to align it with i. It does not mean the earthquakes occurred 0.10 s apart. The exported differential travel time is dt(i−j) = (pick_i−origin_i) − (pick_j−origin_j) − lag. Template-derived picks can change correlation windows and noise estimates, so accepted-pair counts need not increase even when more traces have picks.

For accepted observations, DDCorr remeasures signed r on the filtered waveforms at the fitted lag. Peak acceptance and the peak-gap test use the sampled curve. The coefficient audit lists both lags, both coefficients and any fallback to the sampled value.

Files and conventions

  • dt.cc: travel time i minus j; weight mode cc_squared.
  • Correlation audit: signed r, lag, peak gap, SNR and components.
  • Catalogue · Stations · ID map.
  • Effective settings · Run summary · Group decisions.

Parabolic lag interpolation improves grid resolution; it is not an uncertainty estimate. Correlation weights are not inverse timing variances. Review sparse support, competing peaks, near-identical traces and inconsistent cycles before interpreting relocated structures.

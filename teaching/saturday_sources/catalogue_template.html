Open files from a different run

Choose the input catalog.txt from the run and the two files ending in _filt.txt from its graphsplit_output folder. Their last column must contain the same integer event IDs across stages. Only the input catalogue is required.

Each row has year, month, day, hour, minute, seconds, latitude, longitude, depth in kilometres, an optional magnitude, then the event ID. Filtered files contain only events supported at that stage. A full GraphSplit file can include carried-forward locations. Use a single run’s files. All processing happens in this browser.

How to read and reuse the plots

Each point represents one earthquake in one catalogue. The selected ID is outlined, and a line joins its available stages. Click a point or choose its ID above. Depth increases downwards. The section includes the entire north–south width of the plotted sample. Both panels use the same east limits and equal kilometre scales. The full view retains the same axes as you switch stages.

The local projection approximates east and north distances on a sphere near the centre of the input earthquakes. It is intended for regional sequences. The displacement table uses this same projection. Coordinates and depth changes describe movement between solutions. They do not give a location uncertainty.

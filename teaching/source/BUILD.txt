Rebuilding the editable Friday presentation

Students use teaching/DDCorr_minicourse.pptx directly. All photographs and figures used by the builder are in teaching/assets. The slide text, links, section times and instructor notes are in teaching/source/content.mjs. The builder creates native text, editable tables and diagrams, and places scientific figures at their original aspect ratios.

For an instructor build, install @oai/artifact-tool, @napi-rs/canvas and sharp on the Node module path. The following command, run from the repository root, writes work/slides-build/candidate.pptx:

    node teaching/source/build.mjs

To render PNG previews as well, add --render. To run the publication checks, set PRESENTATION_SKILL_DIR to the presentation toolkit directory containing container_tools/artifact_tool_utils.mjs, RUNTIME_NODE_MODULES to the authoring runtime's modules, and PYTHON_EXECUTABLE to its Python interpreter. Then run:

    node teaching/source/build.mjs --final --render

The validated file is teaching/DDCorr_minicourse.pptx. DDCORR_SLIDES_BUILD and DDCORR_SLIDES_OUTPUT can specify alternative paths.

Regenerating the scientific figures

From the repository root, with Iceland100 extracted alongside DDCorr.jl:

    julia --project=. teaching/source/method_examples.jl ../Iceland100 work/method-curves
    julia --project=. teaching/source/export_trace.jl ../Iceland100/sac/S1_009900/Z7.KVER..HHZ.sac work/field-trace
    python teaching/source/method_figures.py work/method-curves work/field-trace teaching/assets

For the synthetic and header/UTC comparison plots, first generate the synthetic SAC archive as in Start Here. Then run:

    julia --project=. teaching/source/export_synthetic_windows.jl examples/synthetic/sac DDCorr.toml work/method-curves/synthetic.csv
    python teaching/source/lab_figures.py ../Iceland100 work/method-curves/synthetic.csv teaching/assets

The Python plotting environment needs NumPy, Matplotlib, SciPy and ObsPy.

For the wider Iceland maps and the GrowClust example, obtain the full Data Set S1 catalogue (see START_HERE.md) and the Spanish Springs GrowClust reference output (pinned URL in seminar_provenance.json). Generate the KVER samples, then substitute your two downloaded file paths:

    julia --project=. teaching/source/export_kver.jl ../Iceland100
    python teaching/source/seminar_figures.py --workshop .. --s1 S1.txt --growclust spanish_springs.out --out teaching/assets

PROVENANCE.json, seminar_provenance.json and lecture_provenance.json give figure credits and underlying data. lecture_figures.py reproduces the new shared-path, matched Hayward locations, waveform, lag, subsample and timing-graph illustrations. The pinned Hayward input files are listed in lecture_provenance.json. measurement_figures.py plots the direct/FFT comparison and the S correlation peak. Run each script with --help or consult its usage header. The Julia code excerpt PNGs show exact lines in src/signal.jl and the corresponding slides link to that source. Detailed reproduction of existing reference plots uses export_examples.jl, workshop_figures.py and make_figures.py in this folder.

The classroom plot walkthrough uses only the 100-event Iceland field report and its data. Its filter audit also shows the filter response measured with calibration sinusoids. The legacy synthetic figure utilities above are only needed when rebuilding earlier figures. The real-data examples in the Friday edition can also be reproduced from the field and method exports above:

    python teaching/source/measurement_figures.py work/method-curves teaching/assets
    python teaching/source/field_filter_figures.py work/field-trace work/method-curves teaching/assets
    python teaching/source/lag_figure.py work/method-curves teaching/assets/iceland_competing_lags.png
    python teaching/source/threshold_figure.py ../Iceland100/reference teaching/assets/iceland_p_threshold.png
    python teaching/source/clinic_windows.py ../Iceland100 teaching/assets/clinic_cut_requirements.png

For the panels in the report walkthrough, open ../Iceland100/reference/report.html. Summary and closure panels come from the figures linked under Quality and connectivity and Cycle consistency. The two P and S matrix examples come from the station/phase section. The field spectra and filter-response measurements appear in the Filter audit. The source filenames and the event, station and phase identifiers for waveform examples are given on the slides or in their notes.

The UTC comparison for events 85/86 checks equal samples across all 33 channels and reads signed coefficients from the reference CSV:

    python teaching/source/pair_85_86.py ../Iceland100 teaching/assets/iceland_pair_85_86.png

For the marker-relative grid figure, run export_trace.jl on Z7.KVER..HHZ.sac in folders S1_009900 and S1_009901, writing to work/grid/event1 and work/grid/event2 respectively. Then run:

    python teaching/source/pair_sample_grid.py work/grid/event1 work/grid/event2 teaching/assets/kver_pair_sample_grid.png

method_examples.jl exports kver_fft.csv directly from DDCorr.correlation!. measurement_figures.py checks the direct normalized sums against all 51 values before drawing the FFT comparison.
